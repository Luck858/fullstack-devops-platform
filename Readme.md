# Full-Stack DevOps and Cloud Platform

## Project Overview

A full-stack User Management application
built using React, Node.js and PostgreSQL.

The platform will be containerized using Docker,
provisioned using Terraform on AWS, deployed
using Kubernetes and automated using GitHub Actions.

## Technology Stack

- React
- Node.js
- Express.js
- PostgreSQL
- Docker
- Terraform
- AWS
- Kubernetes
- GitHub Actions

## Application Features

- Add users
- View users
- Delete users
- PostgreSQL database integration
- REST API
- Backend health checks

## Local Development

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
npm run dev

### Database

PostgreSQL runs locally through Docker.
